# Candidates inbox

A candidate is a proposed resource awaiting your approval. File one as
`YYYY-MM-DD-<slug>.md` using the guide template (Status: candidate) plus a
**## Evidence** section: which sessions/tasks hit the gap (≥ 2 sessions, or
≥ 3 times in one session). Creation is gated on approval — never auto-create.
Approved candidates get a real guide in ../guides/ and an index row; this
file then moves to done/ (git history keeps the trail).
