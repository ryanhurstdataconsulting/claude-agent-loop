**157 skills across 33 role families.** Each is a full, generic, publication-safe `SKILL.md` an agent loads when a task matches its trigger. This file is the browsable index; the skills themselves live in `payload/skills/<name>/`.

`★` marks a **cross-cutting** skill — one that recurs across several roles, so it is built once and consumed by many. Skills install via the MANIFEST and are invocable with the `Skill` tool once installed.
