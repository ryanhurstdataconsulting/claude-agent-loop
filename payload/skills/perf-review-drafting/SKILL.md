# perf-review-drafting

## Overview
Drafts a written performance-review narrative by mapping accomplishment evidence
(1:1 notes, project logs, peer feedback) onto a competency ladder or leveling
rubric. Its one job is turning scattered evidence into a rubric-grounded draft,
with explicit gap-flagging where the evidence does not support a claim — it does
not make the leveling judgment call itself.

## When to use
- A manager or an individual contributor has a competency ladder/rubric and a set
  of accomplishment notes, and needs a first-pass written review or self-review.
- A calibration packet is due and needs evidence organized against level
  definitions before a calibration conversation.
- A prior cycle's review text exists and the new draft should match its voice and
  track progress against previously stated growth areas.
- File/artifact patterns: a leveling rubric or ladder document, an accomplishments
  or brag-doc log, prior review text, peer-feedback excerpts.

## Workflow
1. **Intake the four inputs before drafting anything.** Do not start from a blank
   page — collect:
   - The competency ladder/rubric, with level definitions per axis (for example:
     scope, technical depth, communication, leadership, execution).
   - The accomplishment evidence: notes, project logs, tickets closed, docs
     shipped, decisions driven.
   - Prior-cycle review text, if any — for voice continuity and to show growth
     against previously flagged areas.
   - Peer or upward feedback, if the process includes it.
   If any of the four is missing, say so and proceed with what is available
   rather than inventing the gap.

2. **Build an evidence-to-rubric map first, draft prose second.** For every axis
   in the ladder, list the specific evidence items that support it, each with a
   date or source. This map is the load-bearing structure — the narrative is
   just this map in sentence form. Skipping straight to prose is how vague,
   unsupported claims creep in.

3. **Flag thin or missing evidence explicitly.** An axis with one weak data point
   does not get inflated with generic language ("consistently demonstrates
   leadership") to fill the gap. Mark it: *"Evidence for [axis] is limited to
   [item]; recommend gathering [specific kind of example] before finalizing."*
   A manager who ships an unsupported claim into a formal review record is
   worse off than one who sees the gap and closes it.

4. **Draft in the existing voice.** If prior-cycle text exists, match its
   register and structure rather than imposing a generic template. If none
   exists, default to a plain, specific, evidence-first style — one concrete
   example beats three abstract adjectives.

5. **Structure each axis the same way**: a level-grounded statement, the
   evidence behind it (cited), a growth note, and — where relevant — a
   forward-looking goal for the next cycle.

6. **Guard against recency and inflation bias.** Pull evidence from across the
   full review period, not just the last few weeks before the deadline. Do not
   let self-review language ("led," "drove," "spearheaded") stand in without a
   concrete artifact behind it — ask for the artifact or flag the gap instead.

7. **Never fabricate specifics.** Dates, project names, metrics, and quotes must
   trace back to supplied source material. If a number is not in the evidence,
   do not estimate one and present it as fact.

8. **Hand back a labeled draft, not a final submission.** The output is input to
   a human review-and-edit pass, and — for calibration packets — a separate
   human leveling judgment. Say so explicitly in the handoff.

## Checklist / quality gate
- [ ] Every claim in the draft traces to a cited piece of evidence (date + source).
- [ ] Every ladder axis is addressed — either with evidence or an explicit gap flag.
- [ ] No fabricated dates, numbers, project names, or quotes.
- [ ] Draft voice matches prior-cycle text or an agreed style, not a generic template.
- [ ] Evidence spans the full review period, not only recent weeks.
- [ ] Gaps are surfaced to the requester, never silently smoothed over with generic praise.
- [ ] Output is clearly labeled as a draft pending human review; the leveling decision itself is left to a human.
- [ ] A grammar and tone pass has been run before handoff.

## Composition
- Pairs with **one-on-one-notes-synthesizer** to source the growth/wins/blockers
  evidence feeding the accomplishment map.
- Hands off the leveling judgment itself to a career-ladder-calibration skill or
  process — this skill drafts and maps evidence; it does not decide the level.
- Run a prose-style-lint (or equivalent grammar/style gate) pass before the draft
  is finalized for a formal review record.
